一、项目简介
 
本项目为物联网工程专业嵌入式实训 OLED 显示综合实验，基于 STM32F103C8T6 单片机完成 0.96 寸 I2C 接口 OLED 屏幕的驱动开发与图形库移植实训。工程包含标准库裸机驱动与 HAL库 U8g2 图形库移植两套完整方案，全程采用 DAP-Link 进行程序下载与在线调试，硬件通信引脚固定使用单片机 I2C2 外设对应的 PB10、PB11 引脚，不使用默认 I2C1 引脚，实现了静态文字显示、长文本滚动播放、自定义图片显示、官方 Demo 界面渲染等多项 OLED 基础显示功能。
 
本实验从底层软件 I2C 模拟时序到硬件 I2C 外设配置、从裸机寄存器开发到成熟图形库移植，完整覆盖了嵌入式屏幕显示开发的基础流程，适合新手学习 I2C 通信协议、OLED 点阵显示原理以及嵌入式图形界面开发思路。
 
二、硬件资源说明
 
- 主控芯片：STM32F103C8T6 最小系统板
- 显示设备：0.96 寸 I2C 接口 OLED 显示屏（SSD1306 驱动、128*64 分辨率）
- 调试烧录设备：DAP-Link（采用 Serial Wire 调试模式）
- 通信总线：硬件 I2C2
- 通信引脚定义：
- PB10 —— I2C2_SCL（时钟引脚）
- PB11 —— I2C2_SDA（数据引脚）
- 通信方式：半双工 I2C 串行通信，仅两根信号线即可完成设备通信

- 调试方式：DAP-Link 在线仿真、断点调试、硬件下载烧录

五、核心技术要点
 
1. 区分软件I2C与硬件I2C
本次实验同时使用两种 I2C 驱动方式：标准库采用软件时序模拟，不占用硬件外设；HAL 库采用硬件 I2C2 外设，由单片机硬件自动生成时序，通信速率更高、代码更简洁、稳定性更强。
2. 引脚适配改造（本次实验重点）
常规网络教程默认使用 I2C1(PB6/PB7)，本工程全部针对性修改为 I2C2(PB10/PB11)，同时适配 DAP-Link 下载调试，解决了默认引脚不匹配、工程直接编译黑屏、通信失败等常见问题。
3. U8g2 库深度裁剪与移植
对开源图形库进行轻量化裁剪，剔除无用屏幕驱动与通信协议，仅保留本次实验所需设备驱动，减小工程体积，提高代码运行效率，同时手动对接 HAL 库 I2C 发送函数，完成底层适配。

七、实验问题与解决总结
 
1. 初次移植 U8g2 屏幕黑屏：排查发现是底层通信句柄仍为 hi2c1，修改为 hi2c2 并核对 PB10/PB11 引脚配置后正常点亮。
2. 文字滚动乱码：缓冲区未及时清屏，优化刷屏逻辑、调整刷新时序后解决。
3. 程序下载失败：CubeMX 调试模式未开启 Serial Wire，适配 DAP-Link 调试接口后可正常下载仿真。
 
八、项目总结
 
本次实训通过两套方案完成 OLED 屏幕开发，深入理解了 I2C 串行通信协议原理与 OLED 点阵显示机制。通过手动修改硬件外设、适配非默认引脚、移植成熟图形库，提升了 STM32 工程配置、外设调试、代码移植排错的能力，熟练掌握了 DAP-Link 调试工具的使用方法，为后续嵌入式人机交互界面、物联网终端显示项目开发积累了扎实的实践基础。
